# 0001 — Name: Backroll

Date: 2026-10-21
Question: What do we call it?
Options considered: CrewPilot (taken: Crew Pilot Inc sells field-service software to home-service trades, plus CrewPilot.io, NextCrew's CrewPilot AI, others), PennIt (pennit.com owned by Penn IT; sounds like "permit"), PivotPad (PIVOT is a live registered mark in software classes 009/042; AbMat sells a Pivot Pad), plus 30 trade-vocabulary candidates.
Evidence: No live BACKROLL registration found in software classes. BACKROLLER (Back 2 Health) cancelled 2014. Unrelated open-source KVM backup tool at backroll.io — no market overlap.
Decision: Backroll.
Reasoning: Backrolling is the pass that works sprayed paint in — the step a shortcut skips. Short, spellable, a word painters own.
Approved by: Alec Penn
