# Production rates

This is the one dataset no competitor has. Every number here comes from Alec's own painting years or from a contractor who said it directly.

**Never** pull a number from an employer's files, invoices, bids or systems.

- `rates.csv`: one row per number. `source` is a person's initials or `alec-own`. `confidence` is `from memory`, `his guess`, or `he checked`.
- A range ("150–200") goes in `notes`, with the middle in `sqft_per_hour`.
